Список последних обновлений плагина RegionMC

v2.2 (2026-09-10)

✅ Добавлено

  • Полное дерево прав в paper-plugin.yml: regionmc.*, regionmc.command.*, regionmc.flags.*, regionmc.bypass.*, regionmc.maxregions.*
  • Новое право regionmc.command.example для команды /rg example
  • Wildcard-обработка в PermissionUtil — цепочка regionmc.command.info → regionmc.command.* → regionmc.*
  • Права regionmc.command.notifier и regionmc.command.rent
  • Полная поддержка аренды регионов через Vault
  • 📚 KillerCoreAPI — обязательная библиотека. Добавлена информация на сайт.

🛠️ Исправлено

  • RegionHelpCommand теперь корректно скрывает info и list, если нет прав
  • RegionCommand.showHelp() удалён — используется RegionHelpCommand
  • Tab-complete больше не показывает example без права regionmc.command.example
  • Убран examples из tab-complete (только example)
  • В paper-plugin.yml короткие описания прав без подсказок по аргументам
  • Исправлена регистрация команды через PluginCommand.setPermission()

📝 Документация

  • Уточнено количество флагов — 39 (было 36)
  • Актуальные значения флагов по умолчанию из кода
  • Дерево прав обновлено под paper-plugin.yml
  • Добавлен раздел «Зависимости» с информацией о KillerCoreAPI
