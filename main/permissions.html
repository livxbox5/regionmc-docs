🛡️ Байпас — обход защиты регионов (v2.3)

Начиная с версии v2.3 обход защиты работает по гибкой схеме: можно дать игроку глобальный обход всех регионов и при этом исключить конкретные регионы, в которых обход не должен действовать.

ПравоДействие
regionmc.bypass.* Глобальный обход всех регионов сервера
regionmc.bypass Альтернатива без звёздочки — то же самое
regionmc.bypass.<region_name> Обход конкретного региона (имя в нижнем регистре)

⚡ Приоритет: specific > wildcard

Если у игрока есть regionmc.bypass.* = true и при этом regionmc.bypass.spawn = false — регион spawn НЕ будет обходиться, а все остальные — будут. 
# Пример: обход везде, кроме региона spawn
lp user Steve permission set regionmc.bypass.* true
lp user Steve permission set regionmc.bypass.spawn false

# Пример: обход только одного региона test
lp user Steve permission set regionmc.bypass.test true
⚠️ Важно: имя региона в праве указывается в нижнем регистре. Для региона Spawn пишите regionmc.bypass.spawn, а не regionmc.bypass.Spawn.

🔔 Право отключения уведомлений (v2.3)

Уведомления о входе/выходе из региона приходят владельцам и участникам. Для отдельного игрока их можно полностью отключить — например, чтобы администратор не спамился, пока тестирует регионы.

ПравоДействие
regionmc.notify.disabled Отключить уведомления для игрока (все регионы, все события) 
# Отключить уведомления игроку
lp user Steve permission set regionmc.notify.disabled true

# Вернуть уведомления
lp user Steve permission unset regionmc.notify.disabled
⚠️ НЕ используйте regionmc.bypass.notify!
Это право сидит под wildcard'ом regionmc.bypass.* — оно автоматически включается вместе с глобальным обходом и глушит уведомления, даже если вы поставили ему false (в LuckPerms wildcard выигрывает у явного false). Используйте только regionmc.notify.disabled.
